# Study Buddy

Study Buddy is a student productivity and study web application created using HTML, CSS, and JavaScript.

The application is designed to help students organize their academic work, study their notes, and track their progress in one place.

## Features

- Dynamic greeting based on the time of day
- Create, complete, and delete study tasks
- Add courses and due dates to tasks
- Automatic task progress tracking
- Create and manage study notes
- Generate flashcards from study notes
- Generate quizzes based on study notes
- Track completed tasks and study progress
- Light and dark mode
- Responsive webpage design
- Sidebar navigation between different sections
- Local storage for saving user data

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Local Storage API
